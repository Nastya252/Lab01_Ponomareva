Гипотеза: Я считаю, что число логических процессоров = 12, потому что AMD Ryzen 5 2600 имеет 6 физических ядер, а SMT позволяет каждому ядру обрабатывать 2 потока одновременно. Следовательно, ОС видит 6 × 2 = 12 логических процессоров.

## Контрольные вопросы
1. Программа запрашивает данные у самой системы
2. ОС выступает посредником. Она управляет доступом 
к процессору, памяти, файлам
3. 64-битная операционная система использует 64-битную архитектуру и способна работать с гораздо большим адресным пространством, чем классическая 32-битная система
4. Environment.ProcessorCount возвращает число логических процессоров, видимых ОС; не обязательно совпадает с числом физических ядер (например, если используется технология SMT)
5. Память процесса WorkingSet является специально выделенной памятью под данный процесс
6. Результаты разные, потому что код запрашивает характеристики среды выполнения, которые на разных компьютерах различаются.
## Итоговый вывод 
Связка «программа — ОС — компьютер»: C# не обращается к cведениям о компьютере напрямую, а запрашивает данные у ОС, которая контролирует доступ к ресурсам и возвращает актуальные сведения.
В ходе работы получены: Environment.MachineName вернул уникальное имя ПК DESKTOP-KEVIKO2, Environment.OSVersion - версию ОС Microsoft Windows NT 10.0.19045.0, Environment.ProcessorCount - число логических процессоров на моём ПК: 12, Environment.WorkingSet - объём памяти процесса 15 МБ.
Одинаковый код даёт разные результаты на разных ПК, поскольку считывает динамические параметры среды, уникальные для каждой системы и момента исполнения.
Программа сама узнаёт данные компьютера, потому что берёт нужные данные у операционной системы - та как раз и служит связующим звеном с оборудованием
2488k
## Дополнительное задание. Мини-монитор системы 
### Что делает программа 
Выводит системную информацию: имя ПК, пользователь, версия ОС, разрядность, число логических процессоров. Получение PID текущего процесса через currentProcess.Id. Трёхкратный замер WorkingSet64 с конвертацией в МБ и обновлением данных через Refresh().
### Что нового я узнал о классе Process
Process управляет данными о процессах ОС.
### Сравнение памяти программы и Диспетчера задач
Значение памяти из программы соответствует значению в Диспетчере задач - оба отражают объём физической RAM, выделенной процессу.
### Почему значение памяти может немного изменяться
Значение памяти изменяется из‑за работы сборщика мусора .NET, выделения/освобождения временных объектов в коде и динамического перераспределения RAM операционной системой.
